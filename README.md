# ShopProject — учебный интернет-магазин

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина:
главная страница, каталог, страница товара, страница заявки и контакты.
Проект выполнен без CSS-фреймворков; JavaScript используется только для
открытия модального окна и базовой проверки формы.

## Ссылка на опубликованный проект

GitHub Pages: https://andreyracl.github.io/kr1-html-css-shop/

## Используемые технологии

- HTML5 (семантические теги, формы, таблицы, `<dialog>`, `<details>`);
- CSS3 (переменные, Flexbox, Grid, позиционирование, состояния);
- методология БЭМ;
- JavaScript (минимально);
- Git, GitHub, GitHub Pages.

## Что реализовано

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`; на каждой странице один `main`.
- **Навигация:** единое меню на всех страницах, активный пункт (`site-nav__link--active` + `aria-current`), хлебные крошки, якорные ссылки `#advantages` и `#popular`.
- **Карточки товаров:** блок `product-card` с изображением, категорией, ценой, бейджем и модификаторами `--featured`, `--discount`.
- **Таблица:** характеристики товара на `product.html` (`caption`, `thead`, `tbody`, `th`, `td`).
- **Формы:** заявка в модальном окне на главной и полная форма на `order.html` (имя, e-mail, телефон, товар, тема, комментарий, согласие); у всех полей есть `label`, `name`, обязательные поля помечены `required`.
- **Модальное окно:** `<dialog>` с формой заявки.
- **CSS:** переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`.
- **Flex/Grid:** Flexbox — меню и кнопки; Grid — сетка товаров, макет каталога, страница товара, страница заявки.
- **Позиционирование:**
  - `position: relative` — карточка товара и контейнер картинки товара;
  - `position: absolute` — бейджи «Хит», «Новинка», «−20%»;
  - `position: sticky` — блок фильтров в каталоге;
  - `position: fixed` — кнопка «Наверх»;
  - `z-index` — для бейджей, фильтров и кнопки «Наверх» (значения вынесены в переменные `--z-sticky`, `--z-fixed`).

## Самостоятельные доработки

- страницы `product.html` и `order.html`;
- изображения товаров и расширенный каталог из 6 карточек с категориями;
- бейджи с модификаторами `product-card__badge--hit / --new / --discount` и отображение старой цены;
- блок преимуществ в виде сетки карточек;
- sticky-фильтр каталога и фиксированная кнопка «Наверх»;
- блок отзывов на странице товара;
- блок «Частые вопросы» на `contacts.html` (через `<details>`);
- в модальном окне показывается выбранный товар;
- кнопки с модификаторами `button--primary` и `button--secondary`;
- доступность: видимый фокус, `aria-current` для текущей страницы, `aria-describedby` для подсказки телефона, `role="status"` для сообщения об отправке.

## БЭМ-структура проекта

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `page` — основное содержимое страницы (`main`);
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `advantages` — преимущества;
- `info-box` — информационная врезка;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product` — подробная страница товара;
- `product-table` — таблица характеристик;
- `reviews`, `review` — отзывы;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-layout` — структура страницы заявки;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки (модификатор `--page` для формы на отдельной странице);
- `success-message` — сообщение об успешной отправке;
- `faq` — частые вопросы;
- `button` — кнопка;
- `to-top` — кнопка «Наверх»;
- `site-footer` — подвал сайта.

Стили задаются только через классы: `id` используются для якорных ссылок и JavaScript, inline-стили не используются.
